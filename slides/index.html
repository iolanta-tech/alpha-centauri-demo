Comments

"@context":
  # dollar-convenience supplies $id and $type, so they can stay unquoted
  "@import": https://json-ld.org/contexts/dollar-convenience.jsonld
  schema: https://schema.org/
  dbo: http://dbpedia.org/ontology/
  dbp: http://dbpedia.org/property/
  dbr: http://dbpedia.org/resource/
  # name is shorthand for schema:name
  name: schema:name

  # walk dbp:star backwards to the planets that orbit this star
  is-orbited-by:
    "@reverse": dbp:star

# red dwarf; frequent flares
$id: dbr:Proxima_Centauri
$type: dbo:Star
name: Proxima Centauri
is-orbited-by:

  # possibly tidally locked; maybe rocky; mass similar to Earth
  # Located in the star's habitable zone, so might have liquid water on the surface
  - $id: dbr:Proxima_Centauri_b
    $type: dbo:Planet
    name: Proxima Centauri b

  # likely rocky; more like Mercury
  - $id: dbr:Proxima_Centauri_d
    $type: dbo:Planet
    name: Proxima Centauri d
20–21 min. JSON has no comments. YAML-LD treats # as whitespace, so the planet notes never become triples.

& anchors, *aliases

"@context":
  dbo: http://dbpedia.org/ontology/
  dbp: http://dbpedia.org/property/
  dbr: http://dbpedia.org/resource/

  # &iri labels this complete term definition
  dbp:star:            &iri
    "@type": "@id"

  # *iri reuses it for the other IRI-valued terms
  dbp:discoveryMethod: *iri
  dbp:discoverySite:   *iri

"@id": dbr:Proxima_Centauri_b
dbp:star:            dbr:Proxima_Centauri
dbp:discoveryMethod: dbr:Doppler_spectroscopy
dbp:discoverySite:   dbr:European_Southern_Observatory
21–22 min. Anchors label a complete YAML value and aliases substitute it wherever reused. JSON-LD receives three ordinary IRI term definitions. The label iri is YAML serialization detail, not RDF data.
22–23 min. YAML has an unquoted NO. What does a processor make of it?

YAML 1.1

country: NO
→
country: false
22–23 min. Under legacy YAML 1.1 rules, the unquoted NO value resolves to the boolean false.

YAML-LD requires YAML 1.2+

23–24 min. YAML-LD processors must use YAML 1.2 or a later backwards-compatible specification.

YAML 1.2+

country: NO
→
country: "NO"
24–25 min. YAML 1.2 Core Schema keeps the JSON-LD value as the string “NO”. The same legacy problem affects yes, no, on, and off.

Keys are strings

mapping-key-error

"@context":
  dbp: http://dbpedia.org/property/
  dbr: http://dbpedia.org/resource/
  xsd: http://www.w3.org/2001/XMLSchema#
  dbp:discovered: { "@type": xsd:date }
  dbp:star: { "@type": "@id" }
  dbp:discoverer: { "@type": "@id" }

? { "@id": dbr:Proxima_Centauri_b,
    dbp:star: dbr:Proxima_Centauri }
:
  dbp:discovered: 2016-08-24
  dbp:discoverer: dbr:Guillem_Anglada-Escudé
25–26 min. YAML accepts this triple-shaped object as a complex mapping key. YAML-LD rejects it: JSON-LD property names are strings, which may expand to RDF predicate terms. Proxima b’s discovery was announced by the team led by Guillem Anglada-Escudé in 2016.
