The Norway problem

22–23 min. YAML has an unquoted NO. What does a processor make of it?

YAML 1.1

country: NO
→
country: false
22–23 min. Under legacy YAML 1.1 rules, the unquoted NO value resolves to the boolean false.

YAML-LD requires YAML 1.2+

23–24 min. YAML-LD processors must use YAML 1.2 or a later backwards-compatible specification.

YAML 1.2+

country: NO
→
country: "NO"
24–25 min. YAML 1.2 Core Schema keeps the JSON-LD value as the string “NO”. The same legacy problem affects yes, no, on, and off.

25–26 min. YAML accepts this triple-shaped object as a complex mapping key. YAML-LD rejects it: JSON-LD property names are strings, which may expand to RDF predicate terms.
