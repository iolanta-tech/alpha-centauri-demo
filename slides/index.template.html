20–22 min. YAML-LD 1.0 is a Working Draft on the W3C Recommendation track, published by the JSON-LD Working Group. YAML-LD mandates YAML 1.2 or a later backwards-compatible processor. Source: https://www.w3.org/TR/yaml-ld/.

24–25 min. JSON has no comments. YAML-LD treats # as whitespace, so the planet notes never become triples. SPARQL still sees Proxima and the planets that orbit it.

Markdown-LD

YAML-LD front matter carries the graph. Markdown carries the reader-facing explanation.

---
"@context":
  "@import": https://json-ld.org/contexts/dollar-convenience.jsonld
  dbr: http://dbpedia.org/resource/
$id: dbr:Alpha_Centauri
name: Alpha Centauri
---

# Alpha Centauri

Alpha Centauri is the closest star system to the Solar System.
